# Основы программирования перед изучением Python

**BrainCode / Tech Orda · Подготовительный справочник для начинающего**

Это **минимум общих понятий**, который поможет понимать объяснения преподавателя и не путаться в словах. Здесь нет сторонних библиотек. Сначала прочитай определения, затем попробуй объяснить их своими словами. Примеры можно запускать в Python.

> **Источники:** официальный силлабус BrainCode (вводный модуль), презентация преподавателя «Урок 02 — Jupyter & Colab» и инструкции проекта. Подробные определения компилятора, байт-кода, алгоритма и остальных общих понятий — **дополнительные объяснения наставника**, а не цитаты из лекции.

## 1. Программа (program)

**Для чего:** программа сообщает компьютеру, какие действия выполнить и в каком порядке. Например, посчитать сумму и показать ответ.

```python
price = 100
quantity = 3
print(price * quantity)
```

**Результат:** `300`. Первая строка сохраняет цену, вторая — количество, третья умножает числа и выводит ответ.

## 2. Код (code) и исходный код (source code)

**Что это:** код — инструкции на языке программирования. **Исходный код** — текст этих инструкций, написанный человеком, например в файле `main.py`.

```python
print("Привет!")
```

**Результат:** `Привет!`. Эта строка — исходный код Python.

## 3. Язык программирования (programming language)

**Для чего:** это набор правил, по которым мы записываем инструкции. Python — один из таких языков. Компьютер не понимает обычные русские предложения как Python-код.

```python
print(2 + 3)
```

**Результат:** `5`. Python понимает запись `print(...)` и арифметическое выражение `2 + 3`.

## 4. Интерпретатор (interpreter)

**Для чего:** программа, которая обеспечивает выполнение написанного кода. Когда ты запускаешь Python, он читает инструкции и выполняет их.

**Пример:** ты сохранил `print("Hello")` в файле `hello.py` и запустил `python hello.py` в терминале. Python выполнит код и покажет `Hello`.

**Важно:** стандартный Python (CPython) обычно сначала преобразует код в **байт-код**, а затем выполняет его. Для начала не нужно изучать детали этого процесса.

## 5. Компилятор (compiler)

**Для чего:** переводит код из одного представления в другое, чтобы его можно было выполнить или обработать дальше. Например, компилятор языка C может создать машинный код программы.

**Простой пример-сравнение:** компилятор похож на переводчика, который сначала подготавливает перевод инструкции; интерпретатор — на исполнителя, который помогает выполнить инструкции. Это упрощённая аналогия: реальные языки могут сочетать оба подхода, в том числе Python.

## 6. Машинный код (machine code) и байт-код (bytecode)

**Машинный код:** инструкции, которые процессор выполняет непосредственно.

**Байт-код Python:** промежуточная форма инструкций, которую обычно выполняет виртуальная машина Python. **Пока достаточно знать различие; писать байт-код вручную не нужно.**

**Схема:** исходный код `.py` → обработка Python → байт-код → выполнение → результат.

## 7. Файл и расширение файла (file, extension)

**Для чего:** файл хранит информацию. Расширение подсказывает тип файла.

| Пример | Что хранит |
|---|---|
| `main.py` | Исходный код Python |
| `lesson.ipynb` | Jupyter Notebook: ячейки с кодом, текстом и результатами |
| `notes.txt` | Обычный текст |
| `data.csv` | Табличные данные в текстовом формате |

**Пример:** файл `hello.py` может содержать `print("Привет")`. Имя файла не является командой Python.

## 8. Редактор кода и IDE

**Редактор кода:** приложение, в котором удобно писать код (подсветка синтаксиса, подсказки).

**IDE (integrated development environment):** среда разработки с инструментами для написания, запуска и отладки программ. Например, PyCharm — IDE; VS Code — редактор, который с расширениями поддерживает многие возможности IDE.

**Пример:** ты набираешь `print(10)` в редакторе, сохраняешь файл, затем запускаешь его. Сам редактор не равен интерпретатору Python.

## 9. Терминал (terminal) и консоль (console)

**Для чего:** позволяют вводить текстовые команды и видеть текстовые результаты.

**Пример команды терминала:**

```text
python hello.py
```

Она запускает файл через Python. **Это команда терминала, а не строка, которую надо вставлять внутрь Python-кода.**

## 10. Jupyter Notebook и ячейка (cell)

**Для чего:** Jupyter позволяет держать код, объяснения и результаты в одном файле `.ipynb`. Код выполняется по отдельным ячейкам.

**Пример ячейки Code:**

```python
x = 5
print(x + 2)
```

**Результат:** `7`. В ячейке Markdown можно написать обычное объяснение, например «Здесь мы прибавляем 2».

**Полезно:** `Shift + Enter` запускает текущую ячейку и переходит к следующей.

## 11. Ядро Jupyter (kernel) и состояние программы (state)

**Для чего:** kernel выполняет Python-код и хранит созданные переменные, пока работает сеанс.

**Ячейка 1:**

```python
age = 20
```

**Ячейка 2:**

```python
print(age)
```

**Результат:** `20`, если первая ячейка уже была выполнена. После перезапуска kernel переменная исчезнет из памяти, пока ты не запустишь первую ячейку снова.

## 12. Алгоритм (algorithm)

**Для чего:** понятный порядок шагов для решения задачи. Алгоритм можно сначала придумать словами, а потом записать на Python.

**Пример алгоритма:** 1) взять два числа; 2) сложить их; 3) показать сумму.

```python
a = 4
b = 6
print(a + b)
```

**Результат:** `10`.

## 13. Входные и выходные данные (input / output)

**Вход:** информация, которую получает программа. **Выход:** результат её работы.

```python
name = input("Как тебя зовут? ")
print("Привет,", name)
```

**Пример:** пользователь вводит `Алия`; программа выводит `Привет, Алия`. `input()` возвращает текст (строку), даже если пользователь ввёл цифры.

## 14. Переменная (variable) и значение (value)

**Для чего:** переменная — имя, по которому программа обращается к значению. Значение — сами данные.

```python
age = 18
print(age)
```

**Результат:** `18`. Здесь `age` — имя переменной, `18` — значение, `=` — присваивание.

## 15. Тип данных (data type)

**Для чего:** показывает, что за значение хранится и какие действия с ним допустимы.

```python
age = 18
name = "Алия"
print(type(age))
print(type(name))
```

**Результат:** `<class 'int'>` и `<class 'str'>`. `int` — целое число, `str` — текст.

## 16. Выражение (expression) и инструкция (statement)

**Выражение:** часть кода, которая вычисляет значение, например `2 + 3`.

**Инструкция:** действие или конструкция языка, например `x = 5` или `if ...:`.

```python
x = 2 + 3
print(x)
```

**Результат:** `5`. `2 + 3` — выражение; `x = 2 + 3` — инструкция присваивания.

## 17. Условие (condition) и ветвление (branching)

**Для чего:** программа выбирает действие в зависимости от того, истинно условие или ложно.

```python
age = 20
if age >= 18:
    print("Взрослый")
else:
    print("Младше 18")
```

**Результат:** `Взрослый`. `>=` означает «больше или равно», а отступы показывают, какие строки относятся к условию.

## 18. Цикл (loop)

**Для чего:** повторяет действия, чтобы не писать одну и ту же строку много раз.

```python
for number in [1, 2, 3]:
    print(number)
```

**Результат:** числа `1`, `2`, `3` на отдельных строках. Цикл `for` перебирает элементы списка.

## 19. Функция (function)

**Для чего:** именованный набор действий, который можно вызывать многократно. Функция может получать входные значения и возвращать результат.

```python
def double(number):
    return number * 2

print(double(4))
```

**Результат:** `8`. `def` создаёт функцию, `number` — параметр, `4` — аргумент при вызове, `return` возвращает вычисленное значение.

## 20. Ошибка (error), баг (bug) и отладка (debugging)

**Ошибка:** код написан неправильно или выполняет не то, что ожидалось. **Баг:** дефект программы. **Отладка:** поиск причины и исправление.

```python
print(unknown_name)
```

**Результат:** `NameError`, если имя `unknown_name` нигде не определено. Python сообщает, что не знает такого имени.

**Как действовать:** прочитай последнюю строку сообщения об ошибке → найди указанную строку кода → проверь имя, скобки и типы данных → исправь → запусти снова.

## 21. Синтаксис (syntax) и отступы (indentation)

**Синтаксис:** правила записи кода, как грамматика языка. **Отступы:** пробелы в начале строк, которые в Python обозначают вложенные блоки.

```python
if True:
    print("Да")
```

**Результат:** `Да`. Если убрать нужный отступ перед `print`, возникнет `IndentationError`.

## 22. Комментарий (comment)

**Для чего:** поясняет код для человека. Python игнорирует комментарии при выполнении.

```python
# Это пояснение, а не команда
print(2 * 3)
```

**Результат:** `6`.
