## 1. Первые действия и переменные

### `print()`

**Для чего:** Показывает текст или значение на экране.

**Пример:**

``` python
print("Привет!")
```

**Результат:** `Привет!`

### `input()`

**Для чего:** Ждёт, пока человек введёт текст и нажмёт Enter. Результат
всегда строка.

**Пример:**

``` python
name = input("Имя: ")
print(name)
```

**Результат:** `введённое имя`

### `=`

**Для чего:** Сохраняет значение под именем переменной. Это не проверка
равенства.

**Пример:**

``` python
age = 20
print(age)
```

**Результат:** `20`

### `#`

**Для чего:** Начинает комментарий: Python игнорирует текст после \# в
этой строке.

**Пример:**

``` python
age = 20  # возраст
print(age)
```

**Результат:** `20`

### `type()`

**Для чего:** Показывает, к какому типу относится значение.

**Пример:**

``` python
print(type(5))
```

**Результат:** `<class 'int'>`

### `None`

**Для чего:** Обозначает отсутствие значения. Это не ноль и не пустая
строка.

**Пример:**

``` python
answer = None
print(answer)
```

**Результат:** `None`

## 2. Типы данных и преобразования

### `int`

**Для чего:** Тип целых чисел: 1, 0, -5.

**Пример:**

``` python
age = 21
print(type(age))
```

**Результат:** `<class 'int'>`

### `float`

**Для чего:** Тип чисел с дробной частью; десятичная точка, а не
запятая.

**Пример:**

``` python
price = 12.5
print(price)
```

**Результат:** `12.5`

### `str`

**Для чего:** Тип текста; текст записывают в кавычках.

**Пример:**

``` python
city = "Алматы"
print(city)
```

**Результат:** `Алматы`

### `bool`

**Для чего:** Логический тип: только True или False.

**Пример:**

``` python
is_ready = True
print(is_ready)
```

**Результат:** `True`

### `int()`

**Для чего:** Пытается превратить число или числовой текст в целое
число; дробную часть отбрасывает.

**Пример:**

``` python
print(int("12"))
```

**Результат:** `12`

### `float()`

**Для чего:** Превращает числовой текст или число в число с дробной
частью.

**Пример:**

``` python
print(float("3.5"))
```

**Результат:** `3.5`

### `str()`

**Для чего:** Превращает значение в текст, например для подписи.

**Пример:**

``` python
print(str(25) + " лет")
```

**Результат:** `25 лет`

### `bool()`

**Для чего:** Преобразует значение в True или False: например, 0 и
пустая строка дают False.

**Пример:**

``` python
print(bool(0))
```

**Результат:** `False`

### `кавычки`

**Для чего:** Одинарные и двойные кавычки обозначают строку; числа в
кавычках становятся текстом.

**Пример:**

``` python
print("5")
print(5)
```

**Результат:** `5, затем 5 (но типы разные)`

### `f-строка`

**Для чего:** Вставляет значения переменных внутрь текста через фигурные
скобки.

**Пример:**

``` python
name = "Алия"
print(f"Привет, {name}!")
```

**Результат:** `Привет, Алия!`

## 3. Арифметика и полезные встроенные функции

### `+`

**Для чего:** Складывает числа; также соединяет строки.

**Пример:**

``` python
print(2 + 3)
```

**Результат:** `5`

### `-`

**Для чего:** Вычитает числа.

**Пример:**

``` python
print(9 - 4)
```

**Результат:** `5`

### `*`

**Для чего:** Умножает числа.

**Пример:**

``` python
print(3 * 4)
```

**Результат:** `12`

### `/`

**Для чего:** Делит и возвращает результат типа float.

**Пример:**

``` python
print(8 / 2)
```

**Результат:** `4.0`

### `//`

**Для чего:** Делит с округлением результата вниз до целого (в том числе
для отрицательных чисел).

**Пример:**

``` python
print(7 // 2)
```

**Результат:** `3`

### `%`

**Для чего:** Возвращает остаток от деления. Полезно для проверки
чётности.

**Пример:**

``` python
print(7 % 2)
```

**Результат:** `1`

### `**`

**Для чего:** Возводит число в степень.

**Пример:**

``` python
print(2 ** 3)
```

**Результат:** `8`

### `abs()`

**Для чего:** Убирает знак минус: показывает, насколько число далеко от
нуля.

**Пример:**

``` python
print(abs(-7))
```

**Результат:** `7`

### `round()`

**Для чего:** Округляет число. При ровно половине Python иногда выбирает
ближайшее чётное число.

**Пример:**

``` python
print(round(3.14159, 2))
```

**Результат:** `3.14`

### `sum()`

**Для чего:** Складывает числа в списке или другой последовательности.

**Пример:**

``` python
print(sum([2, 3, 5]))
```

**Результат:** `10`

### `min()`

**Для чего:** Находит наименьшее значение.

**Пример:**

``` python
print(min([8, 2, 6]))
```

**Результат:** `2`

### `max()`

**Для чего:** Находит наибольшее значение.

**Пример:**

``` python
print(max([8, 2, 6]))
```

**Результат:** `8`

### `len()`

**Для чего:** Считает элементы списка или символы строки.

**Пример:**

``` python
print(len("кот"))
```

**Результат:** `3`

## 4. Сравнение и логика

### `==`

**Для чего:** Проверяет, равны ли два значения; возвращает True или
False.

**Пример:**

``` python
print(5 == 5)
```

**Результат:** `True`

### `!=`

**Для чего:** Проверяет, отличаются ли значения.

**Пример:**

``` python
print(5 != 3)
```

**Результат:** `True`

### `> и <`

**Для чего:** Проверяют, больше или меньше одно число другого.

**Пример:**

``` python
print(7 > 4)
```

**Результат:** `True`

### `>= и <=`

**Для чего:** Проверяют «больше или равно» и «меньше или равно».

**Пример:**

``` python
print(5 <= 5)
```

**Результат:** `True`

### `and`

**Для чего:** True, только когда оба условия верны.

**Пример:**

``` python
print(5 > 2 and 5 < 10)
```

**Результат:** `True`

### `or`

**Для чего:** True, когда хотя бы одно условие верно.

**Пример:**

``` python
print(5 < 2 or 5 < 10)
```

**Результат:** `True`

### `not`

**Для чего:** Меняет True на False и наоборот.

**Пример:**

``` python
print(not True)
```

**Результат:** `False`

### `in`

**Для чего:** Проверяет, есть ли элемент в коллекции или фрагмент в
строке.

**Пример:**

``` python
print("а" in "мама")
```

**Результат:** `True`

### `is None`

**Для чего:** Проверяет, является ли значение именно None.

**Пример:**

``` python
value = None
print(value is None)
```

**Результат:** `True`

## 5. Скобки, точка, двоеточие, индексы

### `()`

**Для чего:** Используются для вызова функций и группировки действий.

**Пример:**

``` python
print((2 + 3) * 4)
```

**Результат:** `20`

### `[]`

**Для чего:** Создают список или выбирают элемент по номеру; счёт
начинается с нуля.

**Пример:**

``` python
a = [10, 20]
print(a[0])
```

**Результат:** `10`

### `{}`

**Для чего:** Создают словарь или множество (непустое).

**Пример:**

``` python
person = {"age": 20}
print(person["age"])
```

**Результат:** `20`

### `:`

**Для чего:** Начинает блок после if, for, def; также используется в
срезах и словарях.

**Пример:**

``` python
if 3 > 2:
    print("Да")
```

**Результат:** `Да`

### `.`

**Для чего:** Позволяет обратиться к действию (методу) или свойству
(атрибуту) объекта.

**Пример:**

``` python
word = "кот"
print(word.upper())
```

**Результат:** `КОТ`

### `отступы`

**Для чего:** Показывают, какие строки входят в условие, цикл или
функцию. Обычно используют четыре пробела.

**Пример:**

``` python
if True:
    print("Внутри блока")
```

**Результат:** `Внутри блока`

### `индекс [-1]`

**Для чего:** Позволяет взять последний элемент списка или строки.

**Пример:**

``` python
print([10, 20, 30][-1])
```

**Результат:** `30`

### `срез [start:stop]`

**Для чего:** Берёт часть последовательности; правая граница не
включается.

**Пример:**

``` python
print([10, 20, 30, 40][1:3])
```

**Результат:** `[20, 30]`

## 6. Коллекции: хранение нескольких значений

### `list / []`

**Для чего:** Список: упорядоченные элементы, которые можно менять.

**Пример:**

``` python
fruits = ["яблоко", "груша"]
print(fruits[0])
```

**Результат:** `яблоко`

### `tuple / ()`

**Для чего:** Кортеж: упорядоченные элементы, которые нельзя заменить
после создания.

**Пример:**

``` python
point = (2, 5)
print(point[1])
```

**Результат:** `5`

### `dict / {}`

**Для чего:** Словарь: хранит значения по ключам, например возраст по
имени поля.

**Пример:**

``` python
user = {"name": "Алия", "age": 20}
print(user["name"])
```

**Результат:** `Алия`

### `set / set()`

**Для чего:** Множество: хранит уникальные элементы, без
гарантированного порядка.

**Пример:**

``` python
numbers = {1, 1, 2}
print(len(numbers))
```

**Результат:** `2`

### `list()`

**Для чего:** Создаёт список из перебираемых значений.

**Пример:**

``` python
print(list("кот"))
```

**Результат:** `['к', 'о', 'т']`

### `tuple()`

**Для чего:** Создаёт кортеж из перебираемых значений.

**Пример:**

``` python
print(tuple([1, 2]))
```

**Результат:** `(1, 2)`

### `dict()`

**Для чего:** Создаёт словарь; один из способов --- именованные
аргументы.

**Пример:**

``` python
print(dict(age=20))
```

**Результат:** `{'age': 20}`

### `set()`

**Для чего:** Создаёт множество; удобно убирать повторы.

**Пример:**

``` python
print(len(set([1, 1, 2])))
```

**Результат:** `2`

## 7. Методы строк, списков и словарей

### `.lower()`

**Для чего:** Делает буквы строки строчными; исходная строка не
меняется.

**Пример:**

``` python
print("HELLO".lower())
```

**Результат:** `hello`

### `.upper()`

**Для чего:** Делает буквы строки заглавными.

**Пример:**

``` python
print("hello".upper())
```

**Результат:** `HELLO`

### `.strip()`

**Для чего:** Убирает пробелы и переносы по краям строки.

**Пример:**

``` python
print("  кот  ".strip())
```

**Результат:** `кот`

### `.split()`

**Для чего:** Разбивает строку на список частей по разделителю.

**Пример:**

``` python
print("a,b,c".split(","))
```

**Результат:** `['a', 'b', 'c']`

### `.replace()`

**Для чего:** Создаёт строку с заменённым фрагментом.

**Пример:**

``` python
print("кот".replace("к", "р"))
```

**Результат:** `рот`

### `.append()`

**Для чего:** Добавляет один элемент в конец списка; меняет сам список.

**Пример:**

``` python
a = [1, 2]
a.append(3)
print(a)
```

**Результат:** `[1, 2, 3]`

### `.pop()`

**Для чего:** Удаляет и возвращает элемент списка; без номера ---
последний.

**Пример:**

``` python
a = [10, 20]
print(a.pop())
```

**Результат:** `20`

### `.remove()`

**Для чего:** Удаляет первое совпадающее значение из списка.

**Пример:**

``` python
a = [1, 2, 2]
a.remove(2)
print(a)
```

**Результат:** `[1, 2]`

### `.sort()`

**Для чего:** Сортирует сам список и ничего полезного не возвращает
(None).

**Пример:**

``` python
a = [3, 1, 2]
a.sort()
print(a)
```

**Результат:** `[1, 2, 3]`

### `sorted()`

**Для чего:** Возвращает новый отсортированный список, не меняя
исходный.

**Пример:**

``` python
print(sorted([3, 1, 2]))
```

**Результат:** `[1, 2, 3]`

### `.get()`

**Для чего:** Безопасно берёт значение словаря по ключу; если ключа нет,
можно указать запасное значение.

**Пример:**

``` python
user = {"age": 20}
print(user.get("city", "неизвестно"))
```

**Результат:** `неизвестно`

### `.keys()`

**Для чего:** Даёт представление ключей словаря.

**Пример:**

``` python
d = {"a": 1}
print(list(d.keys()))
```

**Результат:** `['a']`

### `.values()`

**Для чего:** Даёт представление значений словаря.

**Пример:**

``` python
d = {"a": 1}
print(list(d.values()))
```

**Результат:** `[1]`

### `.items()`

**Для чего:** Даёт пары (ключ, значение), удобно для цикла.

**Пример:**

``` python
d = {"a": 1}
print(list(d.items()))
```

**Результат:** `[('a', 1)]`

### `.add()`

**Для чего:** Добавляет элемент в множество.

**Пример:**

``` python
s = {1}
s.add(2)
print(len(s))
```

**Результат:** `2`

## 8. Условия и циклы

### `if`

**Для чего:** Выполняет блок кода, только если условие истинно.

**Пример:**

``` python
age = 20
if age >= 18:
    print("Взрослый")
```

**Результат:** `Взрослый`

### `elif`

**Для чего:** Проверяет следующее условие, если предыдущие не сработали.

**Пример:**

``` python
x = 0
if x > 0:
    print("Плюс")
elif x == 0:
    print("Ноль")
```

**Результат:** `Ноль`

### `else`

**Для чего:** Выполняется, если предыдущие условия не подошли.

**Пример:**

``` python
x = -1
if x >= 0:
    print("Не минус")
else:
    print("Минус")
```

**Результат:** `Минус`

### `for`

**Для чего:** Повторяет действия для каждого элемента.

**Пример:**

``` python
for x in [1, 2, 3]:
    print(x)
```

**Результат:** `1, 2, 3 на отдельных строках`

### `range()`

**Для чего:** Создаёт последовательность целых чисел для перебора;
конечная граница не включается.

**Пример:**

``` python
for i in range(3):
    print(i)
```

**Результат:** `0, 1, 2 на отдельных строках`

### `while`

**Для чего:** Повторяет блок, пока условие остаётся истинным.

**Пример:**

``` python
n = 0
while n < 3:
    n += 1
print(n)
```

**Результат:** `3`

### `break`

**Для чего:** Сразу прекращает текущий цикл.

**Пример:**

``` python
for x in [1, 2, 3]:
    if x == 2:
        break
    print(x)
```

**Результат:** `1`

### `continue`

**Для чего:** Пропускает оставшуюся часть текущего повторения цикла.

**Пример:**

``` python
for x in [1, 2, 3]:
    if x == 2:
        continue
    print(x)
```

**Результат:** `1, затем 3`

### `+=`

**Для чего:** Увеличивает переменную на указанное значение (короткая
запись).

**Пример:**

``` python
n = 5
n += 2
print(n)
```

**Результат:** `7`

### `enumerate()`

**Для чего:** Даёт одновременно номер и элемент при переборе.

**Пример:**

``` python
for i, name in enumerate(["А", "Б"]):
    print(i, name)
```

**Результат:** `0 А; 1 Б`

### `zip()`

**Для чего:** Перебирает несколько последовательностей парами;
останавливается по самой короткой.

**Пример:**

``` python
for a, b in zip([1, 2], [3, 4]):
    print(a + b)
```

**Результат:** `4, затем 6`

## 9. Свои функции

### `def`

**Для чего:** Создаёт свою функцию: блок команд с именем.

**Пример:**

``` python
def hello():
    print("Привет")
hello()
```

**Результат:** `Привет`

### `параметр`

**Для чего:** Имя внутри определения функции, которое получит значение
при вызове.

**Пример:**

``` python
def hello(name):
    print(name)
hello("Алия")
```

**Результат:** `Алия`

### `аргумент`

**Для чего:** Конкретное значение, которое передаём функции при вызове.

**Пример:**

``` python
def double(x):
    return x * 2
print(double(4))
```

**Результат:** `8`

### `return`

**Для чего:** Возвращает результат из функции; после return функция
завершается.

**Пример:**

``` python
def add(a, b):
    return a + b
print(add(2, 3))
```

**Результат:** `5`

### `значение по умолчанию`

**Для чего:** Параметр может иметь значение, если аргумент не передан.

**Пример:**

``` python
def hello(name="друг"):
    print("Привет,", name)
hello()
```

**Результат:** `Привет, друг`

### `локальная переменная`

**Для чего:** Переменная, созданная внутри функции, обычно доступна
только внутри неё.

**Пример:**

``` python
def calc():
    x = 5
    return x
print(calc())
```

**Результат:** `5`

## 10. Объекты, методы, классы: минимум для чтения кода

### `объект`

**Для чего:** Любое значение Python --- объект: число, строка, список. У
объекта есть тип и доступные действия.

**Пример:**

``` python
text = "кот"
print(type(text))
```

**Результат:** `<class 'str'>`

### `метод`

**Для чего:** Функция, которую вызывают через точку у объекта.

**Пример:**

``` python
text = "кот"
print(text.upper())
```

**Результат:** `КОТ`

### `атрибут`

**Для чего:** Именованное свойство объекта; обычно читается через точку
без круглых скобок.

**Пример:**

``` python
class Box:
    size = 3
print(Box.size)
```

**Результат:** `3`

### `class`

**Для чего:** Определяет собственный тип объектов; подробно создавать
классы научимся позже.

**Пример:**

``` python
class Cat:
    pass
pet = Cat()
print(type(pet).__name__)
```

**Результат:** `Cat`

### `self и __init__`

**Для чего:** В собственных классах **init** настраивает новый объект, а
self обозначает сам объект. Это тема после основ.

**Пример:**

``` python
class Cat:
    def __init__(self, name):
        self.name = name
pet = Cat("Мурка")
print(pet.name)
```

**Результат:** `Мурка`

## 11. Ошибки и безопасный запуск

### `SyntaxError`

**Для чего:** Python не может прочитать запись: например, забыта
закрывающая скобка.

**Пример:**

``` python
print("Привет"
```

**Результат:** `Ошибка SyntaxError`

### `NameError`

**Для чего:** Используется имя переменной, которое ещё не определено.

**Пример:**

``` python
print(age)
```

**Результат:** `NameError, если age не задана`

### `TypeError`

**Для чего:** Операция не подходит к данным: например, нельзя сложить
число и строку напрямую.

**Пример:**

``` python
print(2 + "3")
```

**Результат:** `TypeError`

### `ValueError`

**Для чего:** Тип преобразования подходит, но содержимое нельзя
преобразовать.

**Пример:**

``` python
int("кот")
```

**Результат:** `ValueError`

### `IndexError`

**Для чего:** В списке нет элемента с указанным номером.

**Пример:**

``` python
print([1, 2][5])
```

**Результат:** `IndexError`

### `KeyError`

**Для чего:** В словаре нет указанного ключа.

**Пример:**

``` python
print({"a": 1}["b"])
```

**Результат:** `KeyError`

### `try / except`

**Для чего:** Позволяет обработать ожидаемую ошибку и продолжить
программу.

**Пример:**

``` python
try:
    n = int("кот")
except ValueError:
    print("Это не число")
```

**Результат:** `Это не число`

### `pass`

**Для чего:** Пустая команда-заглушка там, где блок обязателен.

**Пример:**

``` python
if True:
    pass
print("Готово")
```

**Результат:** `Готово`

## 12. Ещё несколько важных конструкций

### `True / False`

**Для чего:** Два логических значения: истина и ложь. Пишутся с большой
буквы.

**Пример:**

``` python
print(3 > 2)
```

**Результат:** `True`

### `is`

**Для чего:** Проверяет, один и тот же ли это объект; для сравнения
чисел и строк обычно нужен ==.

**Пример:**

``` python
x = None
print(x is None)
```

**Результат:** `True`

### `del`

**Для чего:** Удаляет имя переменной или элемент коллекции.

**Пример:**

``` python
a = [1, 2, 3]
del a[0]
print(a)
```

**Результат:** `[2, 3]`

### `list comprehension`

**Для чего:** Короткий способ построить список из перебираемых значений.
Изучать после циклов.

**Пример:**

``` python
squares = [x * x for x in range(3)]
print(squares)
```

**Результат:** `[0, 1, 4]`

### `метод .count()`

**Для чего:** Считает, сколько раз значение встречается в списке или
строке.

**Пример:**

``` python
print([1, 2, 1].count(1))
```

**Результат:** `2`

### `метод .index()`

**Для чего:** Находит номер первого совпадающего элемента.

**Пример:**

``` python
print([10, 20, 30].index(20))
```

**Результат:** `1`
